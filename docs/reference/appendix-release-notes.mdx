# Appendix F: Release Notes

- **FreeSWITCH (open source):** release notes are published with each release on [GitHub](https://github.com/signalwire/freeswitch/releases).
- **FreeSWITCH Enterprise:** see [FreeSWITCH Enterprise Release Notes](./release-notes-enterprise.mdx) in this manual. The per-release notes it links on GitHub are in the `signalwire/stack` repository, which requires FreeSWITCH Enterprise access.

To check the version you are running, use the `version` command from `fs_cli`:

```text
freeswitch@host> version
```
