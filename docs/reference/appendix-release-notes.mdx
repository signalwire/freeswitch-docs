# Appendix F: Release Notes

Release notes are published with each release on GitHub:

- **FreeSWITCH:** [FreeSWITCH releases](https://github.com/signalwire/freeswitch/releases)
- **FreeSWITCH Enterprise:** [FreeSWITCH Enterprise releases](https://github.com/signalwire/stack/releases)

To check the version you are running, use the `version` command from `fs_cli`:

```text
freeswitch@host> version
```
